## 2. SEO Strategy Principles for the LLM Agent

### 2.1 Always optimize for helpful intent first

Every page should clearly answer a real user problem. Do not create thin keyword pages.

Good page purpose examples:

- Help a contractor estimate materials for a metal stud wall.
- Explain how stud spacing affects a plasterboard partition.
- Show how StudFrame Planner turns dimensions into a skeleton and checklist.
- Compare manual estimation vs. app-generated material planning.

Bad page purpose examples:

- Repeating the same landing page with different city names.
- Creating near-duplicate pages for every keyword variation.
- Publishing generic AI-written construction advice without expert review.

### 2.2 Use UK and international terminology together

Because the target is UK / Europe, always consider both term families:

**UK / Europe terms:**

- plasterboard
- stud wall
- metal stud wall
- metal stud partition
- dry lining
- MF framing / metal framing where relevant
- partition wall
- metal track and stud
- plasterboard calculator

**International / US-influenced terms:**

- drywall
- drywall framing
- drywall calculator
- metal stud framing
- stud and track calculator
- drywall material calculator

Do not choose only “drywall” or only “plasterboard.” Use both naturally.

### 2.3 Brand + descriptor rule

In important places, pair the brand with a descriptive phrase:

- StudFrame Planner — AI drywall & plasterboard metal stud design calculator
- StudFrame Planner — 3D metal stud framing planner
- StudFrame Planner — plasterboard stud wall material checklist tool

This helps both users and search engines understand the product.

### 2.4 Do not overclaim

Never claim that the app provides:

- certified engineering drawings,
- structural calculations,
- building regulation approval,
- guaranteed exact material quantities,
- supplier-specific purchasing guarantees,
- fire/acoustic compliance certification.

Use language like:

- estimated material checklist,
- planning aid,
- non-certified project pack,
- verify before purchase,
- consult a qualified professional where required.

## 9. Technical SEO for Nuxt / Vue

### 9.1 Rendering strategy

Recommended:

- Use SSR or prerendered static pages for public marketing pages.
- Avoid client-only rendering for SEO-critical content.
- Keep `/app` functionality behind authenticated routes where needed.
- Public share links should be `noindex` by default unless the user explicitly chooses public indexing later.

### 9.2 Metadata requirements

Every public SEO page needs:

- unique `<title>`
- unique meta description
- canonical URL
- Open Graph title/description/image
- Twitter/X card metadata
- one H1
- logical H2/H3 structure

### 9.3 Sitemap and robots

Generate and maintain:

- `/sitemap.xml`
- `/robots.txt`

Indexable:

- homepage
- feature pages
- template pages
- use case pages
- docs/guides
- calculator pages with real functionality

Noindex:

- app dashboard
- private projects
- login/register pages where appropriate
- public share links by default
- admin routes
- duplicate parameterized URLs

### 9.4 URL rules

Use lowercase, hyphenated URLs.

Good:

- `/templates/wall-partition`
- `/calculators/metal-stud-wall-calculator`
- `/features/material-checklist`

Bad:

- `/WallPartitionTool`
- `/page?id=123`
- `/best-drywall-plasterboard-metal-stud-wall-calculator-online-free-tool`

### 9.5 Structured data

Use JSON-LD where appropriate:

- `Organization`
- `WebSite`
- `SoftwareApplication` or `WebApplication`
- `BreadcrumbList`
- `FAQPage` for real FAQ sections
- `Article` for guides

Do not add fake ratings, fake reviews, or unsupported structured data.

### 9.6 Image SEO

For product screenshots and diagrams:

- use descriptive filenames,
- use meaningful alt text,
- compress images,
- include width/height to reduce layout shift,
- create custom Open Graph images for key pages.

Example alt text:

> 3D metal stud wall skeleton generated in StudFrame Planner with dimensions and stud spacing labels.

### 9.7 Performance

Prioritize:

- fast initial load,
- lazy-load 3D viewer where possible,
- optimize Three.js bundle size,
- lazy-load demo models,
- compress screenshots and 3D preview assets,
- keep marketing pages lightweight.

The 3D app can be heavier, but SEO landing pages should load quickly.

### Problem

Manual drywall planning often lives in sketches, spreadsheets, notes and guesswork. That makes it harder to explain the project to clients, check quantities and prepare a clean material list.

### Solution

StudFrame Planner gives contractors a guided way to create simple non-load-bearing drywall and plasterboard metal stud structures, review the skeleton visually, and generate a practical project pack.

### Workflow

1. Choose a template or describe the project.
2. Enter metric dimensions and layout details.
3. Review the 3D metal stud skeleton.
4. Generate materials, tools, cut list and build checklist.
5. Export a PDF or share a client preview.

### Supported templates

- Wall partition
- Box / counter frame
- TV wall / shelving frame

### Disclaimer block

StudFrame Planner creates estimated planning outputs only. It does not provide certified engineering, structural calculations, building regulation approval or site-specific construction validation. Always verify dimensions, materials and site conditions before construction or purchase.
